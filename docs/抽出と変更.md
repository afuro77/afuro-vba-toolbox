# 抽出した部品とリファクタリング

2つの提供ブックの処理を調べ、外部の業務シートや設定を必要とせず使える共通処理に整理しました。元のセル内容・業務データ・個人パスは持ち込みません。

## 元処理との対応

| 元処理 | 整理した部品 | 主な整理 |
| --- | --- | --- |
| FindRowByText / FindColByText / FindRow / FindRow2 | AT_FindCell / AT_HeaderColumn | 検索範囲を引数化、検索条件を明示、ワイルドカードを文字として扱う |
| ToSafeSheetName / ExistsSheetName | AT_SafeSheetName / AT_HasSheet / AT_UniqueSheetName | 禁止文字、空名、31文字、重複を処理。ハイフンは保持 |
| CopyTemplateRow / CopyTemplateRowBlock | AT_InsertTemplateRow | 書式・数式・行高を保持。挿入で元行がずれる場合を補正 |
| CopyCalloutsAtSamePosition | AT_CopyCallouts | 対象シートを明示。基本の位置・文字・書式を転記 |
| SetSelection / SetSelectionBorder / SetSelectionOuterFrame | AT_SetAlignment / AT_SetOuterBorder / AT_SetGridBorder | Select不要のRange指定、結合解除を暗黙に行わない |
| SetSelectionInterior / SetSelectionFont / SetSelectionAll | AT_SetFill / AT_SetFont / AT_FormatBlock | フォントと色を引数化。固定定数の依存を撤去 |
| CombineCodeAndName / GetCodeFromCombinedString / GetNameFromCombinedString | AT_CombineCodeName / AT_CodeFromLabel / AT_NameFromLabel | 区切りの長さを固定3文字からLen(separator)へ変更 |
| StrSplit / ReplaceString | AT_SplitText / AT_ReplaceText | VBA標準機能へ集約。空の検索文字による無限ループを解消 |
| ConvertR1C1ColumnToA1 / ConvertA1ColumnToR1C1 | AT_ColumnLetter / AT_ColumnNumber | 26進数でXFDまで対応、Long化、不正値を検出 |
| UnionRange | AT_UnionRange | Nothing対応を維持、別シートの範囲混在を検出 |
| SetFormatRound | AT_RoundNumber | Excel標準の丸めへ集約、補正値の加算を撤去、不明なモードを検出 |
| ConvertBRToNewLine | AT_BrToNewline | 大小文字、br/、br /に対応 |
| SetTimeFormat | AT_FormatCompactDate / AT_TryIsoDate | 桁数だけの切り出しから日付・時刻の検証へ変更 |
| SortSheet / AddNewSheet / IsSheet | AT_SortRange / AT_GetSheet / AT_HasSheet | ThisWorkbook・Selection依存を外し、対象を引数で指定 |
| SetProcessing / DisplayStatusBar系 | AT_PauseExcel / AT_RestoreExcel / clsAT_AppGuard / AT_ShowProgress | 元設定を保存・復元。Trueへ一律に戻す処理を撤去 |
| OutputBookLog / ExportFile / CSV出力系 | clsAT_Logger / AT_WriteUtf8 / AT_ExportRangeCsv | ログ出力先とファイルパスを指定。業務用エクスポート構造の依存を撤去 |
| clsControlCon.Expression / 関連チェックの比較処理 | clsAT_Rule / mdlAT_Validation | 比較条件と数値／文字列を明示。業務設定クラスへの依存を撤去 |
| 行制御・キー別データ抽出／集計 | AT_InsertTemplateRow / AT_FilterMatrix / AT_IndexRows / AT_GroupSum | データを配列で受け取り、索引・抽出・集計を共通化 |

配列・辞書・ファイル・CSVの汎用部品は、上記処理を他のマクロでも組み合わせられるよう追加しています。

## 互換性に関わる変更

- StrSplit由来の分割結果は0始まりの配列。元の専用1始まり配列や戻り値件数とは異なります。
- シート名のハイフンを消しません。重複時はAT_UniqueSheetNameで連番を追加します。
- 列変換はA～XFD。以前の限定範囲を超える列でも正しい変換を行います。
- ROUND_UPは絶対値が増す方向のExcel標準の切り上げ。整数12の切り上げは12で、人工的に13へ進めません。
- 不明な丸めモードはエラーにします。元値へ暗黙に戻す処理はありません。
- コードに区切りがない場合は全体をコードとして返し、名前は空文字列です。
- 日付は不正値を拒否します。Try形式はFalse、表示用変換はエラーで知らせます。
- エラーを握りつぶすコピーを撤去したため、書式・図形等で失敗した場合は呼び出し側で扱います。
- エラー値は欠測や0に変換しません。CSV・集計の入力不備は呼び出し側へ知らせます。

## 業務固有で取り込まなかったもの

帳票コード、固定シート群、設定表、サーバー用インポート形式、帳票間参照式、Key1/Key2の画面イベント、専用ダイアログ、保護解除の固定パスワード、VBAコードの自己削除は、元ブックの業務アプリと一体のため汎用部品へそのまま持ち込んでいません。対応する基礎処理は上表の引数型部品へ整理しています。

テンプレート変換の業務マッピングも今回の共通部品集の本体には含めません。公開を取り消した旧版はローカルに別途残っています。
