# 検証

## 実施済み

`python tools/verify_package.py` で、VBA文字列リテラル・手続き境界・名前の重複・標準モジュールの依存・文字コード・全部入りの整合・公開情報のスキャンを確認しています。VBAコンパイラの代用ではありません。

## Excelで実行するテスト（未実施）

1. テスト用VBAプロジェクトに `vbe/modules` の全11ファイル、`vbe/classes` の3ファイル、`vbe/tests/mdlAT_SelfTest.bas` を取り込みます。
2. VBEでコンパイルします。
3. `AT_RunSelfTests` を実行し、イミディエイトウィンドウのPASSを確認します。

テストは一時ブックを作成し、成功・失敗時とも閉じる形です。列番号の全範囲、空値・0・False、検索文字の*、1セルの配列化、丸め、CSVの引用符・改行・末尾空欄、辞書集計、比較条件、ログの数式化防止、設定復元を確認します。

## ファイル・書式・図形の実環境チェック（未実施）

- 空の一時フォルダでUTF-8出力・読込を往復し、日本語と改行が一致することを確認。
- 同じ出力パスに再実行し、overwrite=Falseで拒否され、既存内容が残ることを確認。
- file / folderの存在、再帰列挙、拡張子、大文字小文字、選択キャンセルを確認。
- テンプレート行を上下両方向へ挿入し、行高・書式・数式・参照が意図通りか確認。
- 必須・重複・数値範囲のチェックを、空文字の数式・0・エラー値で確認。
- 図形は、元位置・サイズ・文字・色・基本フォントを比較。
- clsAT_AppGuardを使う自分のマクロでErr.Raiseを発生させ、エラー後の設定復元を確認。

当該環境でVBEを実行できていないため、使用前のコンパイルと検証が必要です。
